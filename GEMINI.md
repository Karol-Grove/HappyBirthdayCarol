# Project Instructions & AI Agent Rules

## Python Commands & Verification Workflow

When working on Python scripts or test suites in this project, follow these commands:

1. **Dependency Management**:
   - Check and install required packages with `pip`:
     `pip install -r requirements.txt` or `pip install <package_name>`

2. **Running Python Code**:
   - Execute Python scripts using:
     `python <script_name>.py`

3. **Running Python Tests**:
   - Run tests using `pytest` or `python -m unittest`:
     `pytest`
     `python -m unittest`

4. **Automated Verification Requirement**:
   - Before finishing any task involving Python code, always run the relevant Python execution or testing command using shell tools (`run_command`) and verify the output.
